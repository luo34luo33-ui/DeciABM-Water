# DeciABM-Water · 多主体节水决策 AI 仿真沙盒

**Jev＋LLM 混合驱动，让一户农民的投资选择，逐季演化为整个流域的节水结果。**

本作品以农业节水设施推广为情境，将农户、农商行和地方水利局放进同一个动态环境。用户既可以扮演流域管理者，设置干旱、补贴、信贷等情景，观察政策如何影响各方选择；也可以进入「水到田头」，亲自扮演一位农户，体验十个种植季的经营与投资。

作品关注一个具体问题：**当农户的收益诉求、银行的信贷判断与地区的节水目标相互作用时，怎样形成可持续的节水采纳过程？**

## 创新价值

### 1. 用两类 AI 引擎支撑大体量多主体决策

农户数量多、决策频繁，适合由响应快、调用成本低的 **Jev 行为决策模型**输出结构化采纳概率；银行授信和水利政策需要综合权衡与文字依据，由 **DeepSeek 大语言模型**承担策略推理。两类引擎共享环境和经济状态，各自处理适合的任务。

这种分工将大量逐户判断交给轻量行为引擎，把长文本推理集中到银行与水利局，减少高频调用的时间和费用开销，为扩大主体数量、延长模拟周期、开展多轮情景对比提供实现路径。当前界面支持最多 **6个水利局、24个村庄、24家银行和432户农户**。

### 2. 从农户需求出发，形成政策反馈闭环

农户先核算投资与融资缺口，银行据此审批；农户获得真实授信后，再决定安装或等待。本季结算完成后，水利局读取实际采纳、用水、拒贷和经营结果，制定下一季政策。政策影响下一季农户，农户的选择又反馈到银行资金和地区考核。

这一过程把微观选择与宏观治理联系起来，可以观察「补贴提高为何改变融资需求」「贷款获批后农户为何继续等待」「地区之间如何通过配额互助调整考核额度」等机制。

### 3. 将空间扩散、经济账目与 AI 决策放在同一条时间线上

农户具有年龄、操作能力、风险厌恶、收益信心、技术支持和邻里信任等差异化画像，并拥有独立田块、现金与债务。空间生成沿用原 Level3 空间版的 Voronoi 田块与邻接机制，邻里安装情况进入后续决策。

设备当季投资、下一季运行，贷款分五季等额还本，逐季结算水费、补贴、收益和利息。点击节点即可把采纳倾向、审批依据与实际账目对应起来；时间轴回放可同步查看当季拓扑、政策、曲线及原始模型响应。

### 4. 让评审者进入模型，体验人与 AI 的选择

「水到田头」以身份卡、家底信封和每季卷宗组织交互。玩家选择流域中的农户画像，揭晓一次性随机家底，阅读天气、政策、授信和邻里信息，再作出投资选择。提交后展示相同事实下的 Jev 判断，便于比较人的考虑与模型倾向。

玩家的行动真实进入整个流域的结算，并影响后续邻里扩散、银行资金与政策反馈。十季结束后，既能查看个人经营结局，也能查看各地区、银行、村庄和其他农户的整体表现。

## 作品中的三层主体

| 主体 | 决策内容 | 决策引擎 | 主要关注 |
| --- | --- | --- | --- |
| 农户 | 安装节水设备或继续等待 | Jev | 经济收益、家底、风险、融资与邻里 |
| 村级农商行 | 逐户授信与新贷款利率 | DeepSeek | 偿债能力、操作能力、逾期与利息收入 |
| 地方水利局 | 下季水价、设备补贴与配额互助 | DeepSeek | 用水红线、采纳、农户经营与财政支出 |

流域管理局由用户扮演，通过共同环境、文字指示与事件表影响各主体。地方局之间同时存在用水考核竞争和配额互助协作。

## 启动运行

获取源码：`git clone git@github.com:luo34luo33-ui/DeciABM-Water.git`，进入 `DeciABM-Water` 文件夹后按以下步骤启动。

**运行环境：Windows、Python 3.12及以上版本、现代浏览器。项目已在 Python 3.13下验证。**

1. 首次使用时，双击 `install.bat`，联网安装依赖。
2. 双击 `start_backend.bat`，浏览器自动打开 **<http://127.0.0.1:8000>**。
3. 演示期间保持后台窗口开启，结束时在后台窗口按 `Ctrl+C`。

页面、插画和 D3 资源保存在本地，字体使用系统字体。后端使用 FastAPI，前端使用原生 JavaScript 与 SVG，由同一服务提供页面和接口。

完整在线部署时，使用支持 Python 的服务运行 FastAPI，由同一服务提供网页和 `/api` 仿真接口。

| 体验方式 | 操作 | 适合查看的内容 |
| --- | --- | --- |
| 在线模型 | 在「Key 设置」中填写 OpenRouter Key，选择「在线模型」后执行 | Jev 原始倾向、DeepSeek 授信与政策依据 |
| 离线规则 | 选择「离线规则」后直接执行 | 完整逐季流程、经济结算、空间与趋势交互 |
| 运行回放 | 打开「运行记录」，选择示例或导入导出的 JSON | 已保存各季状态、模型输出与主体变化 |

在线农户使用 `typesafe/jev-1.14`，银行和水利局使用 `deepseek/deepseek-v4.1-flash`，均通过 OpenRouter 调用。Key 随当前页面请求使用。每季运行记录保存决策来源、原始响应、解析结果和完整状态。

启动时如提示8000端口已占用，先关闭之前的演示后台窗口，再启动本副本。

## 建议评审路径

### 路径一：观察整个流域如何变化

1. 在首屏点击 **「开始模拟」**。
2. 打开 **「新建运行」**，使用默认3个水利局、每局2村、每村12～18户及预设十季事件，创建新局。
3. 选择 **「离线规则」**、运行 **10季**，观察节水号召、干旱、补贴、信贷收紧与红线收紧依次生效。
4. 切换 **「全流域田块」**，查看村庄两岸分布与安装状态；筛选地方局，点击农户读取画像、倾向及融资信息。
5. 点击银行查看批准、拒贷、授信使用和还款；点击水利局查看政策依据、排名与配额互助。
6. 在底部切换用水、采纳、政策和信贷趋势，拖动时间轴回看关键季节。随后可新建同种子情景，比较不同政策组合。

### 路径二：亲自作出一户农民的选择

1. 返回首屏，点击 **「切换到农户模拟模式」**，选择身份并调整画像。
2. 确认身份，打开家底信封，揭晓 **8,000～36,000元**的随机初始现金。
3. 逐季阅读卷宗，选择安装或等待，结算后查看 Jev 对照。采纳后可一键自动运行剩余季节。
4. 第10季查看个人结局与 **全流域多主体结果**，再进入对应地区、银行和农户的回放。

在线体验可在全模拟页先切换「在线模型」，执行后再进入农户模式，新局会沿用该运行方式及已保存配置。

## 可调情景与观察指标

新建运行支持 **1～6个地方水利局、每个水利局管辖2～4个村庄、每村12～18户**，可调整随机种子、初始现金系数和十季事件表。环境设置可调整供水、用水红线、补贴预算、新授信资金比例及流域管理指示。

初始现金系数默认65%，用于形成差异化融资需求；正常绿色设备贷款参考季利率为3%。由此可以观察从「申请—授信—选择—放款」到后续还本付息的完整过程。

| 观察维度 | 页面呈现 |
| --- | --- |
| 节水与采纳 | 实际用水、红线、同供水条件下的设备节水、安装户数与面积占比 |
| 农户经营 | 现金、净投资、融资缺口、安装时序、贷款本息与采纳倾向 |
| 农村信贷 | 审批清单、授信使用、贷款余额、逾期及实收利息 |
| 区域治理 | 水价、补贴、预算支出、用水考核排名与配额转移 |
